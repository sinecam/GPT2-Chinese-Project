# Data Layout

Large datasets and processed binary files are intentionally ignored by Git.

Recommended local layout:

```text
data/raw/pretrain_corpus.jsonl       # raw Chinese pretraining corpus
data/raw/dialogue_sft.jsonl          # raw instruction/chat data
data/processed/pretrain/train.bin    # generated by scripts/prepare_dialogue_data.py
data/processed/pretrain/val.bin
data/processed/pretrain/meta.json
data/processed/sft/train.bin
data/processed/sft/val.bin
data/processed/sft/meta.json
```

Keep only this README and tiny hand-written samples in the repository. Do not commit `.bin`, `.jsonl`, checkpoints, or downloaded Hugging Face cache files.
