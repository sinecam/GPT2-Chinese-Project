# V4.5 Quality Response-Only SFT

V4.5 is a small corrective SFT run on top of the V4.4 checkpoint. The goal is not to chase the lowest validation loss, but to improve visible answer quality: identity stability, concise explanations, email writing, simple poems, and reduced repetition.

## 0. Keep V4.4 as a display backup

```bash
cd /root/autodl-tmp/GPT2_Medium_Project
source activate_env.sh
export PYTHONPATH=/root/autodl-tmp/GPT2_Medium_Project

mkdir -p checkpoints/archive logs/archive
TS=$(date +%Y%m%d_%H%M%S)

```

## 2. Build the V4.5 JSONL mix

The builder can use whichever local intermediate/raw files exist. Missing files are skipped by the shell loop below.

```bash
INPUTS=()
for f in \
  data/raw/V4.3_sft_mix_filtered.jsonl \
  data/raw/V4.4_identity_boost.jsonl \
  data/raw/BelleGroup_train_2M_CN/train_2M_CN.json \
  data/raw/alpaca_gpt4_chinese.jsonl \
  data/raw/alpaca_gpt4_chinese.json
 do
  [ -f "$f" ] && INPUTS+=("$f")
done

python scripts/build_v45_quality_mix.py \
  --input "${INPUTS[@]}" \
  --out data/raw/V4.5_quality_sft_mix.jsonl \
  --max_records 60000 \
  --scan_limit 1200000 \
  --seed_repeat 80 \
  --max_answer_chars 900 \
  --max_en_ratio 0.22
```

Expected result: usually tens of thousands of filtered examples plus repeated seed examples. It is fine if the final count is below 60k; quality matters more than filling the quota.

## 3. Convert to response-only arrays

```bash
python scripts/prepare_dialogue_response_only_sp.py \
  --tokenizer artifacts/tokenizer_zh_50k/spm_zh.model \
  --input data/raw/V4.5_quality_sft_mix.jsonl \
  --out_dir data/processed/V4.5_sp50k_sft_quality_mix \
  --block_size 1024 \
  --default_system "你是一个中文AI助手。回答要简洁、准确。身份问题只回答你是中文AI助手，不要编造姓名、职业或真实人物身份。" \
  --val_ratio 0.02 \
  --min_answer_chars 8 \
  --max_answer_chars 900
```

## 4. Train V4.5 from the V4.4 checkpoint

Use `--init_from`, not `--resume`, because this is a new fine-tuning run with a fresh optimizer and lower learning rate.

```bash
mkdir -p checkpoints logs

nohup bash -c 'python -m torch.distributed.run --standalone --nproc_per_node=2 scripts/train_gpt2_small_zh_response_only.py \
  --data_dir data/processed/V4.5_sp50k_sft_quality_mix \
  --out_dir checkpoints/V4.5_sp50k_gpt2small_sft_quality_mix \
  --init_from checkpoints/V4.4_sp50k_gpt2small_sft_response_only_mix/ckpt.pt \
  --max_iters 3000 \
  --batch_size 8 \
  --grad_accum_steps 4 \
  --learning_rate 3e-6 \
  --min_lr 5e-7 \
  --warmup_iters 200 \
  --lr_decay_iters 3000 \
  --eval_interval 300 \
  --eval_iters 100 \
  --dtype bfloat16' > logs/V4.5_sp50k_gpt2small_sft_quality_mix.log 2>&1 &
```

Watch the log:

```bash
tail -f logs/V4.5_sp50k_gpt2small_sft_quality_mix.log
```

## 5. Test fixed prompts

V4.5 uses response-only `.npy` arrays, so the old `scripts/evaluate_zh.py` command is not the right prompt test here because it expects `val.bin`. Use the training log for validation loss, and use `scripts/chat_zh.py` or the web UI for answer quality.

```bash
python scripts/chat_zh.py \
  --ckpt checkpoints/V4.5_sp50k_gpt2small_sft_quality_mix/ckpt.pt \
  --tokenizer artifacts/tokenizer_zh_50k/spm_zh.model \
  --system_prompt "你是一个中文AI助手。回答要简洁、准确。身份问题只回答你是中文AI助手，不要编造姓名、职业或真实人物身份。" \
  --max_new_tokens 160 \
  --temperature 0.25 \
  --top_k 30 \
  --top_p 0.85 \
  --repetition_penalty 1.15 \
  --no_repeat_ngram_size 4
```

Test these prompts:

```text
你是谁？
请用三句话解释什么是大语言模型。
什么是人工智能？
深度学习和机器学习有什么区别？
帮我写一封请假邮件。
写一首关于春天的五言诗。
```

## Stop or continue?

Start judging at 3000 iterations. Continue only if the answers are still improving and validation loss is still clearly falling.

To extend the same V4.5 run to 4500 iterations:

```bash
nohup bash -c 'python -m torch.distributed.run --standalone --nproc_per_node=2 scripts/train_gpt2_small_zh_response_only.py \
  --data_dir data/processed/V4.5_sp50k_sft_quality_mix \
  --out_dir checkpoints/V4.5_sp50k_gpt2small_sft_quality_mix \
  --resume checkpoints/V4.5_sp50k_gpt2small_sft_quality_mix/latest.pt \
  --max_iters 4500 \
  --batch_size 8 \
  --grad_accum_steps 4 \
  --learning_rate 3e-6 \
  --min_lr 5e-7 \
  --warmup_iters 200 \
  --lr_decay_iters 4500 \
  --eval_interval 300 \
  --eval_iters 100 \
  --dtype bfloat16' >> logs/V4.5_sp50k_gpt2small_sft_quality_mix.log 2>&1 &
```
