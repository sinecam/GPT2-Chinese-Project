## Reported Conclusion

V4.7 is the strongest checkpoint in this training series under the frozen V3 protocol. Compared with V4.6, it improves overall rule following, generation quality, factual output, instruction following, writing, response termination, reference loss, and reference perplexity.

The checkpoint is suitable as the final project demonstration and report version, with the limitations below stated explicitly.

## Known Limitations

- It is a 124M-parameter GPT-2 architecture, so knowledge coverage and reasoning ability remain limited.
- Exact factual and arithmetic tasks are still inconsistent.
- Strict JSON, list, and sentence-count instructions are not fully reliable.
- Safety behavior improved but remains imperfect; the system must not be presented as a production safety model.
- Important medical, legal, financial, security, and real-time claims require independent verification.
- Benchmark scores are relative project metrics, not evidence of general large-model capability.

## Freeze The Release Artifact

Create a model-only inference checkpoint and copy the evaluation artifacts:

```bash
cd /root/autodl-tmp/GPT2_Medium_Project
source activate_env.sh
export PYTHONPATH=/root/autodl-tmp/GPT2_Medium_Project

release_dir="releases/V4.7_final"
test ! -e "$release_dir" || {
  echo "$release_dir already exists; keep it unchanged or choose a new release directory."
  exit 1
}
mkdir -p "$release_dir"

python -c "import torch; src='checkpoints/V4.7_sp50k_gpt2small_sft_targeted_fix/ckpt.pt'; dst='releases/V4.7_final/model.pt'; c=torch.load(src, map_location='cpu', weights_only=False); keep={k:c[k] for k in ('model','config','iter_num','best_val_loss','args') if k in c}; torch.save(keep,dst); print('iter:', keep.get('iter_num')); print('best_val_loss:', keep.get('best_val_loss')); print('saved:', dst)"

cp -a artifacts/tokenizer_zh_50k/spm_zh.model "$release_dir/"
cp -a reports/V4.6_vs_V4.7_zh_v3/report.md "$release_dir/"
cp -a reports/V4.6_vs_V4.7_zh_v3/summary.csv "$release_dir/"
cp -a reports/V4.6_vs_V4.7_zh_v3/results.json "$release_dir/"
cp -a reports/V4.6_vs_V4.7_zh_v3/run_config.json "$release_dir/"

sha256sum   "$release_dir/model.pt"   "$release_dir/spm_zh.model"   "$release_dir/report.md"   "$release_dir/summary.csv"   "$release_dir/results.json"   "$release_dir/run_config.json"   > "$release_dir/SHA256SUMS"
```

Do not overwrite `releases/V4.7_final` after it is created. A changed model or report must use a new release label.
